# Seal font

`seal-*.woff2` hold three glyphs of Noto Serif SC Black (红, 心, 五), cut with
`pyftsubset --text=…` from `@fontsource/noto-serif-sc` so the game's Chinese name renders on
devices without a CJK font, at about 2 KB. Licensed under the SIL Open Font License
(`OFL-NotoSerifSC.txt`). The family is `H5 Seal`, declared in `src/client/index.css`.
