Bots for the bring-your-own-bot feature (see the main README).

- `starter-bot.js`: the starter bot players can download from the game. It's bundled into the client.
- `escape-bot.js`, `timeout-bot.js`, `slow-start-bot.js`: test bots that try to break out of the
  sandbox or hang it. `scripts/smoke-bot-sandbox.mjs` runs them and checks they're contained.
